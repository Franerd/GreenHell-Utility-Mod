Installation
Download the latest .ghmod file from Releases.
Install it using the Green Hell Mod Loader.
Enable the mod.
Open the console and enter utility.

Safety
CollectNearby accepts only a restricted list of approved ItemIDs.

The all option was intentionally removed to prevent unintended objects
from being moved.

# Utility Mod for Green Hell

Mod independente com comandos utilitários para coleta de recursos,
limpeza de área e auxílio em construções.

## Commands

```text
utility
utility Help
utility FinishNearest [distance]
utility ClearArea [distance]
utility ClearPlants [distance]
utility CollectNearby [ItemID] [distance] [pile|line]
